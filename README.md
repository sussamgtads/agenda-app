# Agenda — Calendário & Kanban

Agenda moderna e intuitiva, inspirada no Calendário do Mac, feita para apresentação/demo. 100% estática (HTML + CSS + JS puro), sem login e sem backend — os dados ficam salvos no navegador (localStorage).

## Funcionalidades

- **Visões**: Mês, Semana e Kanban do dia.
- **Compromissos únicos ou recorrentes**: diário, semanal, mensal ou anual.
- **Tipos**: Evento, Reunião e Tarefa, com cores próprias.
- **Participantes**: adicione pessoas a qualquer compromisso (avatares com iniciais).
- **Kanban do dia**: colunas "A fazer / Em andamento / Concluído", com drag-and-drop entre colunas.
- **Arraste no calendário**: mova um compromisso de um dia para outro.
- **Busca**: filtra por título, notas ou participante.
- **Preview ao passar o mouse**: detalhes do compromisso sem precisar abrir.
- **Tema claro/escuro**, com preferência salva.
- **Responsivo**, para uso em desktop ou celular.

## Como usar

Abra o `index.html` direto no navegador, ou publique via GitHub Pages (Settings → Pages → branch `main`, pasta `/root`).

## Dados

Tudo é salvo localmente no navegador de quem acessa (localStorage). Não há sincronização entre dispositivos nem login — pensado para demonstração e uso pessoal.
